# ECOTRITURA

Landing comercial de **ECOTRITURA — Gestión de Residuos Verdes**.

## Stack
- Python 3
- Flask
- HTML + CSS + JavaScript
- Vercel

## Objetivo
Captación comercial para servicios de chipeado móvil y gestión de residuos verdes, con foco en constructoras, paisajistas, barrios/countries, municipios, quintas y productores.

## Ejecutar localmente
```bash
pip install -r requirements.txt
python app.py
```

Abrir: http://localhost:5000

## Deploy
El proyecto incluye `vercel.json` para despliegue en Vercel con Python.
